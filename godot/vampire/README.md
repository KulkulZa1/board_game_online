# 뱀파이어 서바이버 — Godot 판

웹판 뱀서류 게임(`public/arcade/vampire/game.js`)을 Godot 4 단독 프로젝트로 떼어 낸 뒤, **Godot 으로만 할 수 있는
것**을 얹어 핵앤슬래시 쪽으로 키운 판이다. 웹판은 그대로 남아 있다.
**소스만 커밋한다** — `.godot/`(임포트 캐시)·`export/`(빌드 결과)·`export_presets.cfg`(서명 정보)는 `.gitignore` 로 뺀다.
Godot 4.4 가 만드는 `*.uid`·`*.import` 는 Godot 권장대로 커밋한다.

## 여는 법

1. Godot **4.4 이상 Standard**(.NET 아님)를 설치한다.
2. 프로젝트 매니저 → 가져오기 → 이 폴더의 `project.godot`.
3. ▶ 실행 — 세로 540×960 기준, 창을 가로로 늘리면 월드가 더 넓게 보인다(`aspect=expand`).
   렌더러는 Mobile(Vulkan), 2D HDR 켜짐 — 글로우가 이걸 쓴다.

| 입력 | 키보드 | 터치 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 아무 곳이나 눌러 끄는 조이스틱 |
| 대쉬 베기 | Space / X | — (웹판에도 터치 대쉬가 없다) |
| 오버드라이브 | Q | 오른쪽 아래 OD 버튼 |
| 일시정지 | P / Esc | 오른쪽 위 ⏸ |
| 장비창 (가방·바꿔 끼기·분해) | I / Tab | 오른쪽 위 🎒 (새 장비가 있으면 🎒!) |
| 레벨업 선택 · 리롤 | 1 · 2 · 3 · 0 | 카드 / 리롤 버튼 |
| 메인 무기 변경 | 아래쪽 무기 칸 클릭 | 아래쪽 무기 칸 |
| 소리 끄기/켜기 | M | — |

## 웹판에 없는 것 (Godot 판 전용)

**그림과 소리**
- SVG 스프라이트(`art/`) — 플레이어·몬스터 9종·보스·고블린·장비·상자·도끼·베기 자국. 없으면 원으로 대신 그린다.
- 2D HDR 글로우 + 가산 합성 FX 층 — 광선·폭발·파티클·장비 빛기둥이 번진다.
- 후처리 셰이더(`shaders/post.gdshader`) — 폭발 충격파 굴절, 피격·진화 색수차, 비네트, 저체력 붉은 맥동, 혈월·오버드라이브 색조, 낙뢰 섬광.
- 바닥 셰이더(`shaders/ground.gdshader`) — 월드 좌표로 그린 석판·얼룩·금, 맵마다 색이 다르다.
- 실루엣 셰이더 — 피격 흰 번쩍임, 빙결·기절·점화 깜빡임, 대쉬 잔상.
- 핏자국 데칼(몬스터마다 색이 다르고 서서히 사라짐), 튀어 오르는 조각, 카메라 펀치·흔들림.
- 합성 효과음 20종(`scripts/vs_sfx.gd`, 파일 없이 시작할 때 만든다) — 보석을 연달아 먹으면 음이 올라간다.

**규칙**
- **드롭률 하향** — 아이템 상자 40초→75초, 보스 상자 4→1, 고블린 상자 2→1, 정예 파워업 100%→30%, 리롤권 5%→1%.
- **새 무기 3종 + 진화** — 채찍(앞을 넓게, 3레벨부터 양쪽) → 피의 채찍, 도끼(위로 던져 떨어짐) → 죽음의 나선,
  뇌우(무작위 낙뢰·기절) → 천벌.
- **몬스터 9종** — 구울, 흡혈박쥐(지그재그), 해골 전사(35% 다시 일어남), 해골 궁수, 산성 슬라임(분열),
  망령(주기적 반투명 — 피해 70% 감소), 룬 골렘(예고 후 내려찍기, 넉백 무시), 폭탄 임프(붙으면 자폭),
  돌격 멧돼지(예고선 후 돌진).
- **정예 특성 9종** — 분열·흡혈·신속·소환사·폭발·냉기·보호막·거대·순간이동. 5분 뒤 2개, 무한 모드 3개.
- **30분 생존이 클리어** — 맵과 상관없이. 적 성장은 '단계 시간'(`C.stage_seconds`)으로 잰다: 20분까지는 웹판
  10분 곡선을 절반 속도로(웨이브·보스 시계 포함), 20~30분은 0.9배속에 체력 지수 증가·공격 곡선 급상승·이속 증가,
  클리어 뒤 무한 웨이브는 2배속. 목표 생존율(봇 기준)과 맞춘 방법은 아래 '밸런스'.
- **장비** — 4부위(투구·갑옷·장화·반지), 희귀도 5단계(일반·마법·희귀·세트·전설), 옵션 12종.
  정예 10%, 보스 100%(희귀 이상), 고블린 100%(마법 이상), 일반 0.15% — 행운으로 늘어난다. 희귀 이상은 빛기둥과 이름.
- **장비 성장** — 밟은 장비가 지금 낀 같은 부위 장비보다 못하면 **그 장비의 경험치로 분해**된다. 경험치가 차면
  장비 레벨이 오르고(최대 Lv20, 레벨당 옵션 +8%), **Lv5·10·15 에서 각성** — 무작위 발동 옵션이 붙는다.
  빈 부위면 바로 끼고, 더 좋거나 희귀도가 높거나 세트·전설이면 **가방**(8칸)에 들어간다.
- **장비창** (I / Tab / 🎒, 게임이 멈춘다) — 낀 장비 4칸(레벨·경험치), 가방, 고른 장비의 옵션·발동 옵션·비교.
  [장착] 하면 빼낸 장비는 레벨을 지닌 채 가방으로, [분해] 하면 들인 경험치의 60% 가 지금 낀 장비로 돌아간다.
  [약한 장비 모두 분해] 는 세트·전설·더 좋은 것만 남긴다.
- **발동 옵션** — 조건 6종(처치·치명타·피격·대쉬·7초마다·학살) × 효과 8종(화염 신성·서리 폭발·운석우·연쇄 번개·
  블랙홀·칼날 폭풍·천둥·광란). 희귀 25%·세트 35%·전설 100% 로 하나 달고 나오고, 각성으로 늘어난다(최대 3).
  피해는 '그때 잡몹 체력의 몇 배' 라서 얻은 순간 화면을 쓸어 내지만, 20분 뒤로는 장비 레벨로만 커진다.
  발동은 줄에 세워 0.05~0.17초 뒤 터지므로 처치 → 발동 → 처치가 연쇄로 번진다 (한 프레임 4개, 같은 옵션 재발동 대기).
- **제단** — 75~115초마다 근처에 하나. 분노(피해 ×2)·광란(쿨다운 -40%)·혼돈(처치마다 무작위 발동)·탐욕(경험치 ×2,
  장비 ×3)·폭풍(낙뢰)·파멸(주변 적 날림).
- **학살** — 0.35초 틈으로 이어진 처치가 12·30·60·120 을 넘으면 SLAUGHTER·MASSACRE·ANNIHILATION·APOCALYPSE —
  화면 흔들림·멈칫·충격파·색수차가 단계마다 세진다. 끝나면 최종 처치 수를 띄운다.
- **세트 4종** — 잿불 군주·폭풍 사냥꾼·피의 서약·서리 왕관 (2세트·4세트 효과), **전설 4종** — 광전사의 투구·
  가시 갑옷·그림자 장화·탐욕의 반지. 표와 설명은 `scripts/vs_content.gd`.
- **영혼석 영구 강화** — 판이 끝나면 처치·생존 시간·보스·전설로 영혼석을 얻고, 시작 화면에서 힘·활력·신속·지혜·행운을
  산다. 최고 기록과 함께 `user://vampire_meta.cfg` 에 저장된다.

## 밸런스 — 30분 생존 곡선

목표(사용자 요구): 0~20분 생존 99% · 25분 90% · 30분(클리어) 70% · 그 뒤 무한 웨이브는 70% 미만.
사람 대신 `tests/balance_sim.gd` 의 봇으로 잰다 — 가까운 적·예고 장판·돌진 선·탄(부채꼴은 한쪽으로 정해 비킨다)을
피하고, 궁수는 잡으러 가고, 안전할 때만 장비·상자·제단·보석을 줍고, 몰리면 대쉬, 다치면 재생·체력을 고르고,
무기 6개까지는 새 무기를 반기고, 20초마다 장비창을 정리한다. **사람 실력은 제각각이라 이 숫자는 '봇 기준'이다.**

```bash
# 시드 101부터 6판, 36분까지 (프로세스 4개로 나눠 돌리면 코어마다 하나)
godot --headless --path godot/vampire --script res://tests/balance_sim.gd -- 101 6 knight normal 0 36
```

판마다 `RUN {json}` 한 줄 — 죽은 시각, 레벨, 장비 레벨, 분마다 살아 있는 적 수(`en_at`), 죽기 전 8초 피해 출처(`death.src`).

측정하면서 고친 것 (모두 Godot 판 전용, 값은 `scripts/vs_content.gd`):

| 문제 (봇 측정) | 고친 것 |
|---|---|
| 웨이브가 실제 시간으로 와서 적 밀도가 2배 → 3~5분 대량 사망, 살아남으면 Lv80·장비 Lv20 폭주 | 웨이브·보스도 단계 시계(`stage_rate`)로 |
| 화살·보스 원형 탄막이 초반 사망 1위 | `enemy_dmg_curve` 0.3 + 0.9·k^2.5 (k = 단계 시간/10분), 보스 탄 ×0.7, 2단계 궁수 3연발 ×0.75, 1단계 궁수 40%→25%, 궁수 체력 ×0.7, 살아 있는 궁수 최대 30 (`ARCHER_CAP`) |
| 재생 패시브를 못 만난 판이 긁힌 상처로 죽음 | 기본 재생 0.8%/초, 시작 체력 +50 |
| 공격력 패시브(×1.18)·'공격력 강화' 상자(×1.2)가 무제한 → 레벨 200 에 피해 수백 배 | 패시브 상한 6, 상자 5번 (`PASSIVE_CAPS`, `ITEM_DMGPERM_CAP`) |
| 흡혈 15% 가 한 방 수만에 붙어 즉시 완치 | 때려서 얻는 회복은 초당 최대 체력 4% (`LEECH_CAP_PER_SEC`) |
| 재생 10%/초 · 이속 ×1.76 → 650마리 속에서도 안 맞음 | 재생 패시브 3, 이속 패시브 3, 재생 합계 4%/초 (`REGEN_CAP`), 무릎 뒤 적 이속 증가 (`enemy_speed_curve`) |
| 적 상한(650)에서 스폰이 멈춰 몇 분 전의 약한 무리만 남음 | 상한이면 가장 먼 일반 적을 걷어 내고 새로 뽑는다 (`_recycle_for`) |
| 발동 옵션이 잡몹 체력을 끝없이 따라가 언제나 한 방 | 20분(단계 600초)까지만 따라간다 (`PROC_STAGE_CAP`) |

결과 (봇, 기사·보통·초원, 영혼석 강화 없음, 시드 5001~5048 48판):

| 생존 | 10분 | 15분 | 20분 | 25분 | 30분 (클리어) |
|---|---|---|---|---|---|
| 목표 | — | — | 99% | 90% | 70% |
| 측정 | 100% | 100% | 96% | 88% | 79% |

시드 묶음마다 ±6%쯤 흔들린다 (48판의 표준오차). 20분 전에 죽는 판은 장비가 거의 안 떨어져 장비 레벨 1~2 로 버틴
판이고, 사망 피해의 대부분은 2단계 궁수 3연발과 정예 궁수다 (`death.src`). 영혼석 강화를 사면 더 오래 산다.

## 검사

```bash
# Godot 없이 (CI 포함) — 웹판과 공유하는 표·효과식·XP 곡선을 game.js 와 대조
node prototypes/godot-vampire-port-test.js

# Godot 이 있는 곳에서 — 실제 GDScript 로 판을 돌린다 (저장소 루트에서)
godot --headless --path godot/vampire --script res://tests/sim_test.gd
```

첫째는 `npm run test:games` 에 들어 있다. 웹판과 **공유하는 부분은 그대로 같아야** 하고, 일부러 바꾼 값은
`GODOT_OVERRIDES`, Godot 에만 있는 무기는 `GODOT_ONLY` 에 사유와 함께 적혀 있어야 통과한다 — 목록에 없는 차이는
실수로 본다. GDScript 를 실행하지는 않는다.

둘째는 무기 30종 단독 20초, 아이템·파워업, 시너지 13종, 레벨업·리롤·진화, 승리(30분)·무한·사망, 장비(희귀도·세트
4종·전설 4종), 장비 성장(분해 경험치·레벨·각성·가방·장비창·가방 넘침), 발동 효과 8종·처치/주기 발동·블랙홀·학살·
제단, 패시브 상한과 시너지 도달 가능성, 30분 곡선, 몬스터 9종 특성, 정예 특성, 새 무기, 드롭률, 영혼석, 봇 플레이를
돌린다 (Godot 4.4.1 에서 198/198, 약 40초). 밸런스 봇(`tests/balance_sim.gd`)은 몇 분~한 시간 걸려서 따로 돌린다. 실패하면 종료 코드 1. **출력의 `SCRIPT ERROR` 도 실패다** — GDScript 런타임 오류는 그 함수만
멈추고 나머지는 계속 돌아서, 통과 수만 보면 놓친다.

## 고치기 전에 읽을 것

- **웹판과 공유하는 규칙을 바꾸면 `game.js` 와 같이 고친다.** Godot 판에서만 바꾸려면 대조 검사의
  `GODOT_OVERRIDES`/`GODOT_ONLY` 에 사유와 함께 올린다.
- **적 루프 안에서 피해를 주면 적이 배열에서 빠진다.** 복사본을 돌고 `dying` 으로 거른다.
- **콜백 대신 후보 배열.** `enemies_near()` — GDScript 람다는 지역 변수를 값으로 잡는다.
- **`randf()` 는 1.0 을 낼 수 있다.** 배열 인덱스는 `_pick(n)`.
- **Dictionary `==` 는 내용 비교다.** 적·투사체는 내부 클래스(참조 비교), 타격 기록은 적 `id`.
  `Array.erase(dict)` 는 수백 개에서 O(n²) — 파티클·젬·링·텍스트는 `_tick_life()` 로 걸러 새 배열을 만든다.
- **`draw_string_outline` 은 이 프로젝트에서 테두리를 그리지 않았다** (Godot 4.4.1, SystemFont·FontFile 모두).
  글자 테두리는 `main.gd` 의 `_text()` 가 4방향 그림자로 흉내 낸다.
- **HDR 색** — 가산 FX 층에서 1 보다 밝은 색(`_hdr()`)만 글로우가 번진다. 너무 많이 쓰면 화면이 하얗게 뜬다.
- **한글 폰트.** 기본 폰트엔 한글이 없어 `SystemFont` 로 OS 폰트를 쓴다. 배포판에선 Noto Sans KR 같은 OFL 폰트를
  번들하고 `_korean_font()` 를 `FontFile` 로 바꾼다.

### 웹판과 일부러 다르게 한 곳 (웹판 버그)

- **진공 청소기 아이템으로 오른 레벨업이 사라진다** — 웹판은 선택 뒤 `state = 'playing'` 으로 덮어쓴다.
- **한 번 얼었던 적은 다시 넉백되지 않는다** — 웹판 `!e.frozen` 은 `frozen` 이 음수로 남으면 거짓이다.
